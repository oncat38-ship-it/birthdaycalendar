# Birthday Palette v0.4

React + Vite + Firebase の誕生日管理アプリです。

## v0.4の変更
- 人物画像・プロフィール画像をブラウザ側で縮小／JPEG圧縮してFirestoreへ保存する方式に変更。Firebase Storageは使用しません。
- 画像は長辺最大480pxを基準に自動調整し、Firestoreの1ドキュメント上限に余裕を持たせるため約95KB以下を目標に圧縮します。
- ToDoカレンダー連携を実装。現在選択中のデータ枠を対象に連携コードを発行し、ToDo側で入力できます。
- 連携コードは10分で失効し、ToDo側には選択した日付の誕生日・名前・画像を読み取り専用で表示します。
- テレビ予定表連携とは別のAPI・D1テーブルを使用します。
- スマートフォンでの一覧・カレンダー・設定の余白や高さを抑え、操作をコンパクトに調整しました。

## Vercel
既存のVercelプロジェクトへ、フォルダ内のファイルを置き換えてデプロイしてください。
Firebaseの環境変数は従来のものをそのまま使用できます。Firebase Storageの有効化は不要です。

## Firestore
既存の保存先構造は維持しています。Firestoreルールの変更は不要です。
画像は各人物ドキュメントの `imageUrl`、プロフィールドキュメントの `avatarUrl` にdata URLとして保存します。画像は自動圧縮しますが、Firestoreの1ドキュメント上限は1MiBなので、極端に大きい画像や既存の大きな備考データがある場合は保存できないことがあります。

## ToDoカレンダー連携
1. Birthday Paletteで対象のデータ枠を選択します。
2. 設定 → ToDoカレンダー連携 → 「連携コードを発行」を押します。
3. ToDoカレンダーの設定 → 誕生日タブでコードを入力します。
4. ToDoカレンダーの日付ページに、その日が誕生日の人が表示されます。

コードは10分間有効です。連携解除はToDo側またはBirthday Palette側から行えます。1つのToDoアカウントには、同時に1つのBirthday Paletteデータ枠を接続します。

## 注意
中継Worker側にも追加設定が必要です。`../tv-todo-bridge/README.md` を参照してください。
